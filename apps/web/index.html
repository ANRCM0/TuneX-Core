使用说明

从“节点管理”确认 Agent 能力和端口授权，再到“转发管理”创建规则。返回 202 Accepted 仅表示任务已持久接收，需进一步查看 Operation 和详情状态。当前控制台不提供独立链路探测，不会把 Agent 在线状态伪装成“业务可用”。

双节点 Relay · 可视化部署

当前仅支持一个入口和一个出口，TLS 1.3 双向认证；所有资源仍由 Control 和 Agent 验证。

第 1 步 · 发布 Transport Profile

发布后锁定 revision；更新同名 Profile 会产生新版本，不会自动修改已有 Forward。仅 scope Owner 可发布。

第 2 步 · 设置出口 Relay Endpoint

TCP 与 UDP Relay 都使用出口侧 TLS/TCP 资源；同时选两种协议至少需要两个不同的内部 TCP 端口。已被活动 Relay 引用的 Endpoint 可能禁止直接修改。

第 3 步 · 预览并创建 Relay Forward

需要两台不同的已授权 Relay Agent，以及已发布、已授予使用权限的 Profile 和有效 Endpoint。
