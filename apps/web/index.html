Desired

用户希望系统如何转发；Revision 代表配置版本。

Operation

Control 是否已经接收、执行或完成部署动作。

Applied

Agent 实际应用且仍新鲜的部署观察结果。

Health

Agent 上报的运行状况；不等于独立端到端探测。

使用说明

从“节点管理”确认 Agent 能力和端口授权，再到“转发管理”创建规则。返回 202 Accepted 仅表示任务已持久接收，需进一步查看 Operation 和详情状态。当前控制台不提供独立链路探测，不会把 Agent 在线状态伪装成“业务可用”。
