# Historical implementations

`v2/` is a read-only historical reference. It is excluded from VNext builds, tests,
runtime images and active GitHub workflows. Do not deploy its installers as VNext.

VNext does not migrate or support the old API, database or Agent protocol. Original
source and attribution are preserved; see [legal/NOTICE.md](../legal/NOTICE.md).

The archived files retain their original paths relative to `v2/`. Their workflows
are archived as data and are no longer GitHub Actions entry points.
