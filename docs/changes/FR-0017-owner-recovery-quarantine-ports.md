## Concrete Need And Existing Extension Limits

scripts/ops/recovery.ts currently restores into a fresh database, then one original
db.transaction performs owner quarantine in a strict sequence. Inline statements
write Telemetry, Station, Notification, Path and Ingress tables in a foreign operator
workflow. Existing stores have ordinary query/command APIs, but their method sets
do not express these original recovery-only sequences. Do not abuse ordinary
update/apply/reconcile, construct an alternate ledger or duplicate kernel rules.

Add minimal native-neutral ports and existing-owner public operations. Keep raw SQL
in each corresponding lower adapter, unknown Station state construction in Station,
Notification clock after endpoint suspension, and shared publication timestamp in
the original caller. Existing APIs with recovery already remain the sole owners.

## Original Transaction Sequence And Contract

Recovery coordinator runs inside the supplied original transaction, in this order:

1. Identity quarantine returns new account credentials.
2. Transport grants, Relay deployment withdrawal, Node credentials/Nodes quarantine.
3. Telemetry10 statements: node heads/points, rollup cursors/buckets, Probe heads/
   points, Host heads/points, Forward heads/points in that order.
4. Station2 statements: exact original9-field mutable unknown state is encoded at
   the original write stage; policy suspended and next_evaluate_at0, then history
   flagged. Do not reuse a deep-frozen helper or resolve/replay events.
5. Notification4 statements: suspend endpoints -> now sample once -> flag delivery
   history -> cancel queued/claimed/retry-wait with claimed outcome unknown/null
   status code -> finish pending attempts unknown with original GREATEST bounds.
   Preserve terminal HTTP evidence, credential references and endpoint rate bounds.
6. Probe history, plan, qualification and Observation declaration original recovery.
7. now sample once, then Path publication event/update, Ingress deployment event/
   update, Ingress migration event/update, each with original shared timestamp.
8. Probe instance/permit recovery; Forward suspension; original RuntimeLedger
   quarantine and Idempotency quarantine; recovery_events insert last, with its
   separate native Date.now and original details encoding.

Preserve old construction timing and lazy unused collaborators in remaining precise
legacy composition bindings. The new coordinator cannot issue capabilities, restart
pending work, refund permits, clear execution leases/fences/retirements or create a
new Authority/ledger. Operational checkpoint deletion is only the already defined
Telemetry behavior; restored samples, immutable definitions/plans/lineage/attempts/
audit/current binding pointers and protected execution history remain retained.
