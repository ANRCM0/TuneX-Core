## Concrete Mixed Source And Decision

The complete original rule-console body has independent batch rules, command CAS
and key capture, precise native source/proposed Profile/path changes, retry-source
selection, acceptance/no-op relationships, first-write preflight, unknown-outcome
replay and stopping later rows. These are reusable product coordination, beyond
native DOM/formatting. The draft22-leaf map therefore cannot classify that complete
file as an L2 implementation. Extract actual state/rules; do not add an empty alias
or weaken L2's prohibition on product command construction.

The original command state remains single: selected Map, plan, active/stopped,
generation and current opaque cancellation handle. L3 creates/owns it and exposes
the same live state to its original native view. The view owns only its original
DOM input Set and invokes owner methods. Native factory takes createCommands as
an injected callback, imports no L3 source, and does not call it until the original
initializer is invoked. It supplies lazy view callbacks; construction must not
call them before the view's state/input declarations initialize.

Native representation effects keep the original id/revision/hash checks, clone/
ordered JSON operations, encodeURIComponent, request options/signal, AbortController,
aborted/throw/abort mechanics, new Date().toISOString, original confirm/newKey and
error String/slice. Their call sites preserve short-circuit/evaluation order rather
than moving native samples into construction or caching getter results.

## Compatibility And Failure Order

Keep original selection10 limit and input reset order; commands prepared before
discard confirmation where originally done, same fixed CAS/key/body, native form
and displayed state. Profile/path batch original validation/order remain; preflight
not reserved/authorization. Retry still performs Operation GET then Forward GET.
Unknown write replay skips replacement preflight; first preflight failure sends no
write. Complete original rejection classification and local abort distinction stay.
Stop aborts only current local request; no remote rollback/cancel. Tail stops on
uncertain/preflight-failed. Finally clears consent/active/controller, renders then
awaits original refresh callback with original failure behavior. No retry, queue,
Scope rebasing, atomic-batch promise or new server capability is added.

The existing rule-console path becomes its exact composition binding, not a new
business composition root. Add literal Control asset union/routes for owner
public.js, service.js and browser-native/rule-console.js with existing MIME/CSP/
reader. Keep package/API old names; source identity, private closure and declaration
layout change explicitly. Existing VM reads old export-function/source bodies, so
later adaptation must use canonical owner/native UI ports and retain coverage;
do not expose production auth/state hooks for the harness.
