## 接口与启用

新增独立默认关闭开关 `TUNEX_OBSERVABILITY_ENABLED=false`，仅精确值 `true` 启用。
它不依赖路由开关，不开启探测、自动选路、TST、告警或修复。部署示例保留关闭值。

- `GET /api/observability/capabilities`：需要认证、有效 Workspace 成员身份及
  `forward:read`、`node:read`；关闭时仍可发现能力和限制，不读取指标存储。
- `GET /api/observability/snapshot?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD`：
  返回 schema version 1。缺省取上海日界的最近七天，含今日；最多 31 个日标签，首尾包含。
  不接受未来、无效、倒序、重复日期或额外查询参数。Workspace 来自既有 `x-workspace-id`
  成员授权，不能在查询参数指定或覆盖。

普通 viewer 可读，自定义角色替换基础权限，缺少任一读取权限时拒绝。
关闭时快照为 `409 observability_disabled`；无成员身份保持 404；非法查询为 400；
超限为 `422 metrics_limit_exceeded`；存储失败为脱敏的 `503 metrics_unavailable`。
接口没有写路由，认证/CSRF/限流失败和读取结果均为 `Cache-Control: no-store`。

数据库读取使用 RepeatableRead 一致快照，不分配 revision、端口、密钥或命令，不更新
报告、用量、部署或租约。最多 256 Node、512 Link、2048 Forward，归档/入口计数各
4096 个聚合身份，目标最多 4096 个、每 Forward 32 个；均查询 limit+1，超限显式拒绝，
不把截断列表或部分求和返回成完整成功。仅查询本空间拥有的节点与 Link，不引入共享/
联邦节点的原始遥测。当前资源引用不在该空间可见节点/Link 集合内时保守拒绝。

## 指标口径

每个 metric 提供 `value`、`unit`、`kind`、`source`、`freshness`。
数值使用字符串，保留 BigInt 精度；归档 Float 沿用已有存储精度，不据此承诺精确金融账单。
`null` 表示没有有效来源，显式上报或持久行中的 `0` 才是零。

| 来源 | 维度与含义 | 时间与覆盖 |
| --- | --- | --- |
| `workspace_archive` | Forward 用其稳定 ID 的 `TunnelTraffic`；Workspace 用不可变 `workspace_id` 的全部归档用量，包含删除后的资源与其他已归档业务 | 上海日标签窗口、`latest_day` 和行数；`historical`，没有采样或接收时间，不能生成实时速率 |
| `tst_ingress_checkpoint` | 按不可变 Forward/Link/入口 Node 身份合计所选日的已收到 producer/day 累计字节和累计连接；Workspace 只合计一次入口事实 | `updated_at` 是最后一次非陈旧样本的 Panel 接收时间；新鲜度仅描述最新接收，不保证全部 producer 仍活跃或窗口采集完整 |
| `node_report` | 节点进程范围的 runtime 数量和累计 apply/runtime 错误，进程启动时间可空；不等于本 Workspace 业务连接或错误率 | Panel 心跳时间，沿用 90 秒窗口；旧凭据世代、吊销、缺凭据、未来时间不得建立 current |
| `target_tcp_connect` | 已有观测表中，与当前配置的本地节点、授权目标匹配的 TCP 建连耗时/可达性；用目标索引表示，不返回地址 | 同时带 Agent 观测时间与 Panel 接收时间，沿用目标观测窗口；失败耗时为 null，0ms 有效；不同目标不平均成整条路径质量 |
| `not_collected` | 尚未采集的 active connections、全路径延迟、业务错误率等 | unavailable/unknown，保持 null |

归档和入口计数可能描述同一业务，**不能彼此相加**。各 hop 字节也不相加为业务总流量。
Link/Node 没有可靠的历史归档归属时，其 archive 指标保持 null，不通过当前 Forward 归属
重写历史。历史入口 checkpoint 可以属于旧 Link/旧 Node，并不会证明当前部署在承载业务。
连接 checkpoint 是所选日的累计计数，不是在线连接数；Node runtime 数不是连接数。

读取窗口不是额度周期：本接口不替换策略/账单的有效周期查询。窗口无归档行时是未知，
不补零，也不宣称没有发生流量。`recorded_rows_only`/`recorded_producer_days_only` 明确表示
仅覆盖存储中已存在的记录，不保证采集或保留完整。TST 沿用既有耐久 spool/去重计量，
未新增 Native 持久计费发送器。

## 状态与边界

Node 的 connection/lifecycle 与 report freshness 分列。Link 的 desired/deployment 与
placement observation 分列；placement 必须匹配当前 Link generation、配置摘要、节点/
角色和有效报告租期，不能用部署 ACK 生成 Ready，凭据轮换前报告也不能生成 Ready。
Ready 仍只是 placement 运行观测，不保证监听、业务路径或目标应用健康。

Forward 单节点或单跳 Native、非 both 的 runtime 投影仅表示**所需 revision 的配置是否
出现在该节点报告中**：`reported`、`absent`、`mismatch`、`unknown`、`stale`。它不验证实际
socket。Native both、多跳、TST 的此配置存在性列表本轮不投影，显式标注 `not_projected`；
TST 的 Link placement 仍可独立读取。目标延迟本轮覆盖 Native TCP/both 的当前直接目标/
活动授权出口池，以及未使用高级目标池的 TST TCP/both 单目标；没有匹配周期性观测时
保持 unknown。本接口不会临时探测目标，不声称覆盖 UDP/TLS 应用健康、TST 高级目标池
或联邦远端。

DTO 使用显式白名单，不返回 Prisma 行、原始报告、端点/目标地址、hostname、runtime ID、
配置摘要、凭据、诊断文本或原始 ORM 错误。尚未交付 O3 的具体错误时间线，不用节点进程
累计错误代替 Forward 的业务错误。

## O2 第一增量：统一监控页面

用户侧导航新增 `/monitor`，复用现有控制台、Workspace 权限投影和中英文界面。
页面先发现能力；开关关闭时只读 capabilities，不请求快照。演示模式同样显示默认关闭，
不生成“在线”采集结果。需要 `forward:read` 和 `node:read`，自定义角色不回退基础权限。

页面默认查询上海日界最近七天；可修改为最多 31 个首尾包含的有效日标签。未提交的
日期编辑不改变当前快照，当前快照的日期与生成时间始终单独标明。无效范围不发请求；
超限、授权失败、存储失败和跨空间/版本/日期不匹配的响应均清除展示，不保留部分结果。
所有指标请求为 GET/no-store，显式捕获 Workspace 和 AbortSignal；切换空间或撤销权限
在渲染时屏蔽旧结果，取消旧请求，迟到响应不能恢复旧数据。查询不签发探测/修复命令。

Workspace 显示归档与 TST 入口累计用量；二者分列，既不相加，也不累加 Node/Link/hop。
十进制字符串保留大整数精度，实测零与缺失值区分。新鲜度、已知失效原因、接收/观测
时间与样本年龄按快照时间标注；手动刷新获取最新事实，不把旧快照称为实时监控。

资源列表按 ID 筛选，每页 20 项，详情可用键盘访问并自动聚焦。Forward 显示配置节点
顺序、载体关联、期望/部署状态、期望/已应用版本、配置存在性及授权目标 TCP 样本；
Link 分列部署世代、节点报告和 Ready；Node 显示连接/生命周期与进程范围遥测。
配置图不是完整数据路径健康图；Ready、ACK、节点在线和配置存在都不建立业务健康。
陈旧成功观测明确为历史样本，不平均成端到端延迟。活跃连接、实时速率、业务错误率、
时间序列和异常时间线仍明确待采集，不使用累计值、历史窗口或空数据伪造趋势。

本地验证：Web 全量 **1430 项 / 10004 断言 / 80 文件**，新增 11 项专项；typecheck 和
Next.js 生产构建通过。真实 Chromium 浏览器 **25 项验收通过**，使用后端纯投影生成的隔离 HTTP fixture 与
生产 CSS，覆盖中英文 × 360/390/768/1024/1280/1536、分页/筛选/详情、精确计数、未知/
陈旧数据、错误分流、权限撤销、跨空间迟到响应与默认关闭；另运行实际 Next.js
`/monitor` 页面认证跳转、权限加载、导航高亮和中英文默认关闭验收。
这不代替真实采集器、生产部署或 WAN 验证。原始截图与 JSON 见忽略工件
`web/test-artifacts/v2.4-o2-browser/`；Linux CI 新增同一浏览器回归并归档截图和日志。
固定提交 CI 结果待本轮发布后登记。

本轮没有数据库迁移、Agent/计费/业务执行链路变更。关闭独立指标开关或回退 Web 即可
停止新页面读取。下一增量优先补充有界真实历史序列与采样覆盖，再推进 O3–O5。
