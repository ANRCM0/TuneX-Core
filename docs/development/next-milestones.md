## 独立环境与发行门槛

- 多 Agent 同机／namespace 证据保持其范围，独立物理主机需要独立场景。
- 长稳、波动、负载和资源测量需完整持续时间、拓扑与故障证据。
- 独立 Responder 构建、版本、打包及发布需自己的交付证据。
- 镜像发布、正式标签、发布接受与生产就绪分别记录，不以 main 合并代替。
