# Control Channel Boundary

Public Go interface 1. Client/Roots/Certificate are
adapter-owned generic types. The native provider retains the original HTTP client,
dynamic client-certificate callback, TLS 1.3 minimum, ten-second timeout, redirect
refusal, JSON content type, optional epoch header and 4194305-byte limited read.

Request adds no retry, authentication, authority cache or fallback. Native status
errors use HTTPError; the legacy Runner request entry converts them to the existing
private httpError code/status shape. CloseIdleConnections is the same owner-triggered
effect, after the original credential/Guard steps and on Run exit.

Auxiliary declares separate instance/claim/delivery/telemetry request effects and
bounded telemetry client cloning. Native profiles retain the original different
URL/refusal/redirect checks. Reply exposes a caller-owned body: the existing owner
still limits/reads it, defers close, checks status/context and validates ACK identity.
No one-use claim, permit, freshness or execution decision moves into the channel.
Telemetry clones preserve their independent pools, limits and two-second bounds.
Request-specific timing uses the injected Scheduler and unchanged owner deadlines.

Legacy helper entries use the original native defaults.

Exact-source verification and remaining environment limits are recorded in
[verification status](../../../docs/testing/verification-status.md).
